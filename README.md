# Cidade & Mudanças Climáticas — Seminário Avançado (Parte I)

Apresentação em HTML para o Seminário Avançado **Cidade & Mudanças Climáticas** (PROURB/FAU/UFRJ), 18 e 25 de novembro de 2026.
Profa. Ana Lucia Brito · Doutorando Felipe Sacramento.

- `index.html` — apresentação (19 slides)
- `roda.html` — roda dos 35 instrumentos da Nota Metodológica (ONU-Habitat), com lista completa
- `assets/js/mapa.js` e `assets/js/mapa-dados.js` — mapa interativo do estado do RJ (municípios, Regiões de Governo, REDECs, Regiões Hidrográficas, consórcios de resíduos sólidos)
- `assets/js/roda.js` — **dados da roda** (edite `GRUPOS`, `ESCALAS` e `INSTRUMENTOS`)
- `assets/img/` — logos e imagens extraídas do .pptx original

## Publicar no GitHub Pages

1. Crie um repositório (ex.: `sa-cidade-clima`) e envie o conteúdo desta pasta para a raiz.
2. Em **Settings → Pages**, escolha *Deploy from a branch*, branch `main`, pasta `/ (root)`.
3. O endereço será `https://<seu-usuario>.github.io/sa-cidade-clima/`.
   A roda fica em `.../roda.html`; um slide específico, em `.../#14`.

## Usar em aula

| Tecla | Ação |
|---|---|
| → · espaço · PgDn | próximo slide |
| ← · PgUp | slide anterior |
| Home / End | primeiro / último |
| F | tela cheia |
| P | imprimir / salvar em PDF (um slide por página) |

No celular, deslize para os lados.
